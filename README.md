# Electricity Consumers

Веб-приложение для работы с электрическими приборами и расчёта нагрузки на электросеть.

В рамках лабораторной работы №3 реализован REST API на Go с использованием Gin.
Данные хранятся в PostgreSQL, работа с БД выполняется через GORM.
Изображения и видео электрических приборов хранятся в MinIO.

## API

Все методы веб-сервиса начинаются с `/api`.

### Электрические приборы

#### GET `/api/electricity_consumers`

Получение списка опубликованных электрических приборов.

Поддерживается фильтрация по мощности:

- `min_power` — минимальная мощность;
- `max_power` — максимальная мощность.

В ответе для каждого прибора передаётся поле `is_creator`:

- `1` — прибор создан текущим пользователем;
- `0` — прибор создан другим пользователем.

---

#### GET `/api/electricity_consumers/feed`

Получение электрического прибора для ленты.

Без идентификатора возвращается опубликованный прибор из ленты.

Для перехода к следующему прибору используется:

`GET /api/electricity_consumers/feed/:id?next=true`

где:

- `id` — идентификатор текущего прибора;
- `next=true` — получить следующий опубликованный прибор.

В ответе передаётся поле `is_liked`:

- `1` — текущий пользователь поставил лайк;
- `0` — лайка от текущего пользователя нет.

---

#### GET `/api/electricity_consumers/draft`

Получение черновика текущего пользователя.

У пользователя может быть не более одного черновика.
Идентификатор черновика в URL не передаётся.

---

#### POST `/api/electricity_consumers`

Создание нового черновика электрического прибора.

Запрос отправляется как `multipart/form-data`.

Передаются:

- `name` — название прибора;
- `image` — изображение;
- `video` — короткое видео.

Изображение и видео сохраняются в MinIO.
Имена файлов генерируются на сервере и сохраняются в базе данных.

---

#### PUT `/api/electricity_consumers/:id`

Публикация черновика электрического прибора.

Передаются поля:

- `description` — описание прибора;
- `power_kw` — мощность прибора в кВт.

На сервере рассчитывается сила тока:

`I = P * 1000 / 220`

После публикации запись получает статус `опубликован` и становится доступна в списке и ленте.

Вернуть опубликованную запись обратно в статус `черновик` нельзя.

---

#### DELETE `/api/electricity_consumers/:id`

Логическое удаление электрического прибора текущего пользователя.

Запись физически не удаляется из базы данных, а получает статус `удален`.

Удалённые записи клиенту не передаются.

---

#### POST `/api/electricity_consumers/:id/likes`

Установка или отмена лайка текущего пользователя.

Тело запроса:

```json
{
  "value": 1
}
```

Значения поля `value`:

- `1` — поставить лайк;
- `0` — убрать лайк.

---

### Пользователи

#### POST `/api/users`

Регистрация нового пользователя.

Тело запроса:

```json
{
  "login": "milena",
  "password": "123456"
}
```

Логин пользователя должен быть уникальным.

---

#### POST `/api/auth/login`

Аутентификация пользователя.

В лабораторной работе №3 метод является заглушкой для лабораторной работы №4.

---

#### POST `/api/auth/logout`

Деавторизация пользователя.

В лабораторной работе №3 метод является заглушкой для лабораторной работы №4.

## База данных

### Таблица `electricity_consumers`

Хранит данные об электрических приборах.

| Поле | Описание |
|---|---|
| `id` | идентификатор прибора |
| `name` | название прибора |
| `description` | описание прибора |
| `status` | статус записи |
| `image` | имя файла изображения |
| `video` | имя файла видео |
| `power_kw` | мощность прибора, кВт |
| `current_a` | сила тока, А |
| `date_create` | дата создания |
| `creator_id` | идентификатор создателя |
| `date_formation` | дата публикации |
| `date_completion` | дата логического удаления |

Возможные статусы:

- `черновик`;
- `опубликован`;
- `удален`.

---

### Таблица `users`

Хранит данные пользователей.

| Поле | Описание |
|---|---|
| `id` | идентификатор пользователя |
| `login` | логин пользователя |
| `password` | пароль пользователя |

Поле `login` является уникальным.

---

### Таблица `likes`

Хранит лайки электрических приборов.

| Поле | Описание |
|---|---|
| `id` | идентификатор лайка |
| `user_id` | идентификатор пользователя |
| `electricity_consumer_id` | идентификатор электрического прибора |

Пара `user_id` и `electricity_consumer_id` является уникальной, поэтому один пользователь может поставить одному прибору только один лайк.
